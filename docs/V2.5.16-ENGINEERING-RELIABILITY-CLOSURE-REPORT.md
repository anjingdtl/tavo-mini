## 3. 代码变更

### 3.1 非法目标章节 position 硬阻断

文件：`src/services/storyMemory/storyMemoryPrepare.ts`、`storyMemoryCoverage.ts`

- eligibility 后、`planStoryMemoryCoverage()` 前：若 `reason === 'invalid_position' && invalidPositionSource === 'target'`，立即返回：
  - `blocked: true`
  - `blockReason: '目标章节位置无效，无法安全构建上下文。'`
  - `coverage = createEmptyStoryMemoryCoveragePlan('invalid_target_position')`
  - `checkpoint: null` / `checkpointUpdated: false`
- 不调用：`planStoryMemoryCoverage`、Checkpoint advance/rebuild、LLM
- `buildContext()` 既有 `if (prepared.blocked) throw` 路径使 preview / generation 均失败

Checkpoint through 非法（`invalidPositionSource === 'checkpoint'`）**不**硬阻断：继续 coverage（from `-1`）、允许 raw/episodic fallback。

### 3.2 `invalidPositionSource`

文件：`src/services/storyMemory/storyMemoryCheckpointEligibility.ts`、`src/services/contextBuilder.ts`

| 场景 | reason | invalidPositionSource | 文案 |
| --- | --- | --- | --- |
| target 非法 | `invalid_position` | `target` | 目标章节位置无效，无法安全构建故事上下文 |
| through 非法 | `invalid_position` | `checkpoint` | 故事记忆检查点位置无效，本次未注入长期故事状态 |
| 其它 reason | * | `undefined` | 既有文案 |

`usable=false` 时 `checkpoint` 仍恒为 `null`；不额外暴露完整 Checkpoint state。

### 3.3 APK 单一验收入口

文件：`scripts/apk-verification-parsers.ps1`、`scripts/verify-release-apk.ps1`

- `Test-ApkSignerAcceptance` 返回：
  - `Accepted` / `Reason`（`ok` | `no_v2_line` | `v2_not_true` | `invalid_signer_count` | `no_cert` | `cert_mismatch`）/ `NormalizedCertSha256`
- 主脚本：

```powershell
$acceptance = Test-ApkSignerAcceptance `
    -Parsed $parsed `
    -ExpectedCertSha256Normalized $script:RELEASE_CERT_SHA256_NORM
if (-not $acceptance.Accepted) {
    throw "APK signer acceptance failed: $($acceptance.Reason). Output:`n$signerOutput"
}
```

- 主脚本仍负责：执行 apksigner、退出码、parser、acceptance、汇总、zipalign、aapt、APK SHA-256
- 主脚本不再独立 if/throw 决策 `V2LineFound` / `VerifiedV2` / `NumberSigners` / 证书比较
