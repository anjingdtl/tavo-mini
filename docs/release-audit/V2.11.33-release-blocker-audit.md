## 7. 未验证项 / 剩余风险

1. **Release 正式签名构建未验证**（无签名密钥环境；构建流程由 `scripts/build-apk.js` 强校验版本一致，风险低）
2. **真实 LLM 端到端批次运行未执行**（需要真实 API Key + 联网；状态机路径由 mock-runner 测试覆盖，网络失败分类已有单测）
3. 规划（`planning`）状态被中断后无「重新规划」出口（预览页只有开始/放弃）：低概率 UX 缺口，P2 记录，建议后续版本在预览页增加重新规划入口
4. 心跳续租在测试中使用下限 10s 未覆盖真实长请求场景（逻辑简单，风险低）
5. `planning` 批次冷启动不归一化（设计选择：规划请求中断后由用户重新进入处理）
