- arm64-v8a 真机 llama.cpp 长上下文、内存峰值、温度、耗电和 unload；
- 厂商 ROM 的 Doze、后台回收、前台服务、系统 TTS 与 SAF；

- V2.5.1 主线推送后的 GitHub Actions 结果应在远端完成后单独确认。

## 设计规范偏差

核心架构、database facade、Schema 迁移、章节事件摘要与 TF-IDF 检索均未简化或删除。
模拟器采用确定性 OpenAI 兼容服务验证协议和运行时闭环，不等同于真实模型语义验收。
