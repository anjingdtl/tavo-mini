# Data Reliability Phase 0–1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish verified quality gates and make schema initialization and migrations transaction-safe without deleting or silently repairing user data.

**Architecture:** Extract a synchronous SQLite transaction scheduler that receives pre-built SQL statements. Convert migration modules from database-mutating async functions to async statement builders, then submit each migration plus its `schema_version` write atomically. Drive runtime validation from one schema manifest and reorder `openDatabase` around install detection, migration, validation, narrow known-defect repair, and seed data.

**Tech Stack:** React Native 0.85, TypeScript 5.8, react-native-sqlite-storage, Jest 29, ESLint, Android Gradle.

- [ ] **Step 3: Implement the minimal executor**

Implement this shape without `await` inside the callback:

```ts
export interface SqlStatement {
  sql: string;
  params?: unknown[];
}

export function executeTransaction(
  database: SQLite.SQLiteDatabase,
  statements: readonly SqlStatement[],
): Promise<void> {
  if (statements.length === 0) return Promise.resolve();
  return new Promise((resolve, reject) => {
    database.transaction(
      tx => {
        for (const { sql, params = [] } of statements) tx.executeSql(sql, params as any[]);
      },
      error => reject(error),
      () => resolve(),
    );
  });
}
```

Move `runInTransactionSafe` callers in `database.ts` to this exported function while preserving their pre-transaction statement collection.
