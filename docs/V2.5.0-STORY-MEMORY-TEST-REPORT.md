## 已知限制与风险

- LLM 提取质量仍受模型能力影响；证据约束能阻止无来源写入，但不能证明模型对正文语义的理解一定正确。
- legacy bootstrap 只使用旧摘要、标题与概要，成本较低但不等同完整正文重建。
- Story Memory renderer 会在预算不足时裁剪人物和关系细节；活跃主线、未解决线索与未兑现伏笔优先保留。
- 新增 Story Memory 模块的聚合覆盖率为 statements 76.87%、branches 58.79%、functions 82.22%、lines 78.07%；已通过仓库现行全局和数据库分层门禁，但尚未达到设计规范建议的 merger/validator/repository/rebuild 单模块高覆盖目标，后续仍需补充异常分支与冲突组合测试。
- 真机和外部模型结果未完成前，不应把 V2.5.0 标记为可分发 RC。

## 后续建议

- 建立规范中的固定 30 章回归小说和可重复的在线/本地模型输出夹具。
- 在真机证据完成后把结果、设备型号、APK SHA-256 和日志路径补入本报告及发布清单。
