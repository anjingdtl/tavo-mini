## 发现并修复的问题

延迟响应期间取消重建时，provider 抛出的取消异常会进入通用 catch，导致状态错误地持久化为
`failed`。`f8218df` 统一识别 `AbortSignal` 与 `cancelled` 错误，将状态恢复为 `dirty`、保留
checkpoint 且不记录失败信息；新增定向回归测试后在模拟器复测通过。
