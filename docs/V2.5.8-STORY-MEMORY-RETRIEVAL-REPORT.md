## 2. 实际采用的查询 / 分词 / 评分 / Top-K

### 查询

```
title + synopsis + retrievalUserPrompt + content[0:800] + previous.content[-800]
```

上一章：`position < current` 且正文非空中 position 最大者。

### 分词

- 英文/数字/`_`：完整 token + 小写 + 原停用词
- 中文连续片段：单字 + 相邻双字 + 相邻三字（O(n)，无四字及以上）

### 评分

```
finalScore = cosine + nameBoost + aliasBoost + objectThreadBoost + pairBoost
```

常量：`0.22 / 0.12 / 0.10 / 0.28`，上限 `0.44 / 0.24 / 0.20`；人物组合奖励只加一次。

排序：`finalScore ↓` → `cosineScore ↓` → `position ↓` → `id ↑`。

### Top-K（topK≥5）

- 相关度桶 ≈60%
- 人物历史桶 ≈20%
- 最近章节桶 剩余
- 去重后按 finalScore 补齐；注入上下文时按 position 升序

`topK<5`：按 finalScore，并至少保留一个最近摘要。

功能开关：`EPISODIC_RETRIEVAL_V2_ENABLED`（默认 `true`）。
