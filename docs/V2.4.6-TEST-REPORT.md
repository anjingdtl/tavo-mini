## 四、发现的已知问题

### 4.1 16KB 页大小兼容性警告（**重要**）

模拟器是 Android 17 (API 37)，强制要求 16KB 页大小兼容。模拟器弹了 **`"Android App Compatibility"`** 警告框：

```
This app isn't 16 KB compatible. RELRO alignment check failed.

The following libraries are not 16 KB aligned:
  lib/x86_64/libllamacpp_jni.so
  lib/x86_64/libappmodules.so
  lib/x86_64/libggml.so
  lib/x86_64/libggml-base.so
  lib/x86_64/libggml-cpu.so
  lib/x86_64/libllama.so
  lib/x86_64/libsqliteJni.so        (RELRO segment not aligned)
  lib/x86_64/libreactnative.so
  lib/x86_64/libhermesvm.so
  lib/x86_64/libhermestooling.so
  lib/x86_64/libfbjni.so
  lib/x86_64/libimagepipeline.so
  lib/x86_64/libnative-filters.so
  lib/x86_64/libnative-imagetranscoder.so
  lib/x86_64/libjsi.so
  lib/x86_64/librnscreens.so
  lib/x86_64/libreact_codegen_rnscreens.so
  lib/x86_64/libreact_codegen_rnsvg.so
  lib/x86_64/libreact_codegen_safeareacontext.so
  lib/x86_64/libc++_shared.so
```

**影响**：
- 当前模拟器用**兼容模式**运行，不会崩
- 真机 Android 15+（2025 年 11 月起强制）**会无法启动**
- 这个属于**RN 0.85 + Android 15+ 平台基础要求**，不是 V2.4.6 新代码引入

**建议**：
- 升级到 RN 0.85.x 的 16KB 兼容 patch
- 或在 `android/gradle.properties` 显式启用 16KB 对齐：`-DANDROID_PAGE_SIZE_16KB=true`
- 或在 `android/app/build.gradle` 的 `externalNativeBuild.cmake.arguments` 加 `-DANDROID_SUPPORT_FLEXIBLE_PAGE_SIZES=ON`
- llama.cpp 第三方源码可能需要重编才能满足

> ⚠️ **发版前必须处理**，否则 Play Store 上架会被拒。

### 4.2 平台工具目录冲突（构建警告）

```
[CXX5304] Observed package id 'platform-tools' in inconsistent location
'C:\Users\Administrator\AppData\Local\Android\Sdk\platform-tools-2'
(Expected 'C:\Users\Administrator\AppData\Local\Android\Sdk\platform-tools')
```

Android SDK 有两个 `platform-tools` 目录。**不影响构建**，但建议清理。

### 4.3 CMKE 长路径警告（构建警告）

```
C/C++: The object file directory has 194 characters.
The maximum full path to an object file is 250 characters
(see CMAKE_OBJECT_PATH_MAX).
```

`@react-native-documents/picker` 的 codegen 路径过长。**当前 Windows 上有 ninja 兜底**（`scripts/build-apk.js` 探测 `C:/Users/${user.name}/.local/bin/ninja.exe`），不影响构建。

### 4.4 adb 中文输入限制（**测试方法局限**）

- `adb shell input text` 不支持非 ASCII（已知问题）
- 测试时项目名/章节名只能用 ASCII（"TestV246"）
- **不影响产品功能**，仅影响测试方法

### 4.5 RN ScrollView + uiautomator dump 兼容性问题

- uiautomator 对 RN ScrollView 内某些按钮的 dump 有时不准确（缓存或 ScrollView 限制）
- 部分屏幕（如备份中心 Modal）dump 显示的还是上一个 activity 的视图
- **实际渲染正常**（截图能看到）
- 测试中用 `KEYCODE_DPAD_CENTER` 或直接 `screencap` 校验最终 UI 状态

### 4.6 原生 Alert 在某些 emulator 上吞触摸事件

测试中发现点击 `Alert.alert` 的"删除"按钮（备份中心删除备份）卡死，但截图能看到 Modal。
- 真机/不同模拟器表现可能不同
- 这是一个**测试环境限制**，不是 App 问题
