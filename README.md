当前版本：**V2.11.2** · 支持 Android 7.0 及以上设备

ShineWriter 是一款面向中文小说创作的 Android 应用。它可以帮助你管理作品、写章节、整理人物和世界观，也可以按你的设置调用 AI 辅助创作。作品数据默认保存在手机本地；是否使用在线模型，始终由你决定。

## 你可以用它做什么

### 从一个故事开始

新建作品后就能建立章节、填写梗概、记录人物和伏笔。编辑器会自动保存，章节还可以保留多个修订版本，方便比较和回退。

如果你已经有完整原著，也可以创建“原著续写”项目：导入原著、设置续写边界、完成 Canon 分析后，再从边界之后继续写新的章节。本地数据库当前为 **Schema 26**。

### 让 AI 帮你，而不是替你失控

你可以配置自己信任的 OpenAI 兼容模型服务，或使用本地 GGUF 模型。AI 能用于续写、润色、生成大纲、构建角色卡和世界书等工作。

原著续写模式会把原著事实、续写前文、已确认的角色状态和故事记忆分开处理：

- 原著规则、人物和剧情由 Canon 提供依据；
- Canon 分析成功后会继续运行**原著写作风格分析**，生成最高强度、可执行的画风画像；原著续写始终严格遵循该画像，未完成或未启用画像时会先阻断续写；
- 续写章节的用户可见编号会接续原著边界（例如边界在第 20 章时，首篇续写显示为第 21 章），内部 position 仍从 0 起，不打乱状态与记忆；
- 上一段原著和最近续写章节会优先保留章末，保证情节自然承接；
- 已定稿章节会逐步沉淀为长期故事记忆，后续章节能继续参考；
- 模型上下文会按实际可用窗口自动分配，窗口更大时会获得更多有价值的前文，而不是机械截断；
- 每次续写前都可以查看“实际请求”和“资料分配”（含原著风格画像的级别 / token / 降级原因，并区分 Planner 与 Writer），知道模型读到了什么。

AI 给出的续写内容仍由你决定是否采纳、修改或定稿。涉及人物关系、世界事实等重要变化，应用会保留可审核的状态建议，不会悄悄把猜测当作既定事实。

### 把资料整理在一起

你可以保存或导入角色卡、世界书、笔记和预设，也可以从文本、角色卡或世界书素材出发构建新资料。

在原著续写项目中，原著信息由 Canon 自动提供。你额外添加的资料只有在明确标为“外部补充”后才会参与续写，避免同一段原著被重复塞给模型。

### 朗读、备份与恢复

- 可使用系统朗读或你配置的语音服务听章节；
- 支持导出 Markdown、纯文本和 `.tavo-novel.json`；
- 支持本地备份与恢复，恢复前会先创建保护性备份；
- API Key 使用 Android 系统安全存储，不会写进项目备份。

## 开始使用

1. 在“项目”页点击“新建”，选择“大纲创作”或“原著续写”。
2. 大纲创作可以直接新建章节开始写；原著续写先进入“原著与 Canon 资料”导入文本并设置边界。
3. 在“设置”页配置在线模型，或导入本地 GGUF 模型。没有配置模型也可以正常写作和管理资料。
4. 在章节编辑页使用 AI 功能前，先通过“上下文预览”检查引用内容是否符合你的预期。
5. 对满意的续写章节执行定稿，让章节状态与长期故事记忆持续更新。

## 数据与隐私

你的章节、人物、世界书、笔记和任务记录默认只存放在设备的应用数据中。

当你主动调用在线模型或云端语音服务时，相关提示词、上下文和待处理文本会发送给你配置的服务商。请在使用前阅读对应服务商的隐私政策。应用默认要求 HTTPS；局域网 HTTP 需要你主动开启并会提示风险。

备份不包含 API Key。换机或恢复备份后，如需继续使用在线模型，请重新填写密钥。

## 常见问题

### 为什么续写前要导入原著并完成 Canon 分析？

这一步会把原著中的规则、人物、关系、经历和剧情线整理为可核对的依据，并在成功后分析原著写作风格。它帮助续写避免与原著矛盾、贴近原著文风，也让你能在需要时追溯参考来源。

### 上下文预览里为什么会出现“系统”和“用户”？

这是模型真正收到的完整请求，不是额外混入原著的内容。“系统”负责说明续写规则和输出格式，“用户”是你的本章要求。点击“资料分配”可单独查看原著、前文和记忆分别占用了多少空间。

### 没有网络还能使用吗？

可以。写作、资料管理、备份、本地导入导出和系统朗读都可以离线使用。只有在线 AI 或在线语音功能需要网络。若使用本地 GGUF 模型，AI 生成也可以不联网。

### 续写内容会自动覆盖我的正文吗？

不会。AI 生成的内容会以草稿或候选结果呈现，由你采纳、编辑和定稿。编辑已定稿章节时，相关续写状态与故事记忆会自动标记为需要重建，避免旧记忆继续影响后文。
